

## 第一步：登录

1. 用浏览器打开 http://47.76.236.148:8000。
2. 输入账号和密码。
3. 看右边的验证码图片，把上面的字符填进去。看不清就点一下图片换一张。
4. 点「登录」。

连续输错 3 次会被锁 30 秒，等一下再试就行。

登录后，左边菜单里有一项「**AI 训练**」，点开是两个页面，你只会用到这两个：

|      |                                          |
| ---- | ---------------------------------------- |
| 页面 | 用来做什么                               |
| 训练 | 录入「训练例子」，点「训练」生成模型版本 |
| 测试 | 录入「测试例子」，点「开始测试」看分数   |

如果界面是英文，点右上角的地球图标，切换到中文。「设置」菜单下的东西不要动。

## 第二步：录入例子并训练

先把截图分成两堆：大约三分之二当「训练例子」（教它），三分之一当「测试例子」（考它）。**同一张图不要两边都放**，不然就是拿例题当考题，分数不准。

### 录入一个训练例子

打开「AI 训练 → 训练」页，点「添加例子」，弹出的框里填四样东西：

1. **图片**：截图后直接在框里按 Ctrl+V（Mac 是 ⌘+V）粘贴；也可以把图片文件拖进来。一个例子最多 5 张图。
2. **问题**：用一两句话说图上是什么，比如「EURUSD 日线，价格突破前高，成交量放大」。写品种和周期会很有帮助。
3. **标准答案**：你当时会怎么做，比如 BUY、SELL 或 HOLD。这是唯一会被打分的部分。
4. **解释（选填）**：为什么这么做。不打分，但 AI 会学你的思路，建议写。

点「确定」保存。重复这一步，把训练那堆图都录进去。

标准答案始终用同一组词。你写过的答案会自动出现在下拉里，直接选就行。如果一会儿写 BUY 一会儿写「买入」，AI 会以为是两个不同的选项。

### 先做一个「基线」版本

基线就是什么都没学过的原始 AI，用来当起点。以后每个版本都跟它比，才知道训练有没有用。

1. 点页面右上角的「训练」。
2. 「版本」写 `基线`，「指令」留空。
3. 「学习哪些例子」选「不用例子（基线）」。
4. 点「确定」。

### 训练你自己的版本

1. 再点一次「训练」。
2. 「版本」可以留空，会按顺序自动起名（基线算第一个，所以这里是 v2）
3. 「指令」里用大白话写你的交易规则，比如「只顺势交易；信号不明确时选 HOLD」。
4. 「学习哪些例子」选「全部训练例子」。想只用一部分，就先在表格里勾选它们，再选「表格里选中的例子」。
5. 点「确定」。一秒钟就好，新版本会出现在下面的「模型版本」表里。

训练不会花时间，是因为它只是把你的指令和例子打包记下来。AI 每次回答问题时，会先看一遍这些例子，再照着你的思路作答。真正花时间的是下一步的测试。

## 第三步：测试和对比

测试就是让某个版本把所有测试例子做一遍，系统自动对答案、算分数。先测基线，再测你的版本，比一比就知道训练有没有用。

### 录入测试例子

打开「AI 训练 → 测试」页，点「添加例子」，用和训练例子一样的方法，把「考它」那堆图录进去。AI 在学习时看不到这些例子，所以分数才可信。每种答案（BUY、SELL、HOLD）都尽量放几道。

### 开始测试

1. 在「测试记录」上方的下拉框里选「基线」。
2. 点「开始测试」。表里会出现一行，进度条自己往前走。
3. 等状态变成「完成」，再选你的版本（比如 v2），重复一次。

要有耐心：AI 跑在没有显卡的服务器上，每道题可能要几秒到几分钟。测试在服务器上跑，关掉网页也不会中断，过一会儿回来看就行。同一时间只能跑一个测试。

### 看懂测试记录

|      |                                                                        |
| ---- | ---------------------------------------------------------------------- |
| 列   | 意思                                                                   |
| 分数 | 答对的比例，比如「70% (7/10)」就是 10 题对了 7 题                      |
| 出错 | 分数后面出现橙色的「N 出错」，是 AI 没答出来，不是答错。可以过会儿重测 |
| 变化 | 和上一次完成的测试比，绿色 +10% 是变好了，红色是变差了                 |
| 详情 | 点开看每道题：你的标准答案、AI 的答案和它的理由、对还是错              |

### 对比两次测试

1. 在测试记录表里，勾选两行（比如基线和 v2）。
2. 点「对比」。
3. 每道题会标上「变对了」「变错了」「都对」或「都错」。

「变对了」是训练教会它的，「变错了」是训练把它带偏的。重点看「变错了」的题，它们告诉你下一轮该改什么。

### 不满意就再来一轮

1. 看详情里 AI 答错的理由，找出它没懂的地方。
2. 去训练页：补几个针对性的例子，或者把指令写得更清楚。
3. 点「训练」出一个新版本，再去测试页测它，和上一版对比。

分数持续比基线高，就说明它真的学到了你的思路。分数和基线差不多，说明例子或指令还没教到点上。

## 常见问题

|                              |                                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 遇到的情况                   | 怎么办                                                                                                       |
| 「开始测试」是灰的，点不了   | 三种可能：没选版本、还没有测试例子、已经有一个测试在跑                                                       |
| 状态变成「失败」             | 服务器中途重启了，重新点「开始测试」就行                                                                     |
| 很多题是「出错」             | AI 服务可能没开好，告诉我                                                                                    |
| 详情里提示「接近上下文上限」 | 例子或图片太多，AI 记不住，最前面的例子会被丢掉。训练时只勾选最有代表性的一部分例子，或者每个例子少放几张图  |
| 改了一个训练例子             | 所有用到它的版本都会跟着变。以前的分数不受影响                                                               |
| 删掉一个版本                 | 它的测试记录也会一起删掉，删之前想清楚                                                                       |
| 想让 AI 看一张新图           | 目前没有单独的提问页。可以把图加成测试例子，跑一次测试，在详情里看它的回答。这会把所有测试题重做一遍，比较慢 |

最后一点：测试题太少时分数会很跳。只有 10 题的话，多对一题就是 +10%。所以别因为一次 +10% 就下结论，测试题积累到 30 题以上，分数才比较靠得住。
